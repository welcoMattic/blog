Securing APIs has become more standardized with modern solutions like OAuth2, OIDC, JWT and rate limiting. 
Now, tools like Keycloak and Symfony's new features simplify implementing these protocols.

As an API developer, you’ll learn to enhance your API's security. 
As an API consumer, you’ll discover how to interact securely with external APIs. 

Join us to master secure API practices, without the complexity!
